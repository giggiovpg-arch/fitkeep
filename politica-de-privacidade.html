Política de Privacidade

Esta Política de Privacidade descreve como o VythaLab coleta, utiliza e protege os dados dos usuários.

1. Dados Coletados

  • Nome e email do usuário
  • Dados de saúde e biometria fornecidos pelo usuário
  • Dados de dispositivos e wearables conectados
  • Informações de uso do aplicativo

2. Uso das Informações

  • Gerar insights personalizados
  • Melhorar funcionalidades do aplicativo
  • Garantir segurança e estabilidade da plataforma
  • Oferecer suporte ao usuário

3. Compartilhamento

O VythaLab não vende dados pessoais dos usuários.

Dados poderão ser compartilhados apenas quando necessário para operação do serviço, cumprimento legal ou integração autorizada pelo usuário.

4. Segurança

Medidas técnicas e organizacionais são utilizadas para proteger os dados contra acesso não autorizado, perda ou alteração.

5. Direitos do Usuário

  • Solicitar acesso aos dados
  • Solicitar correção ou exclusão
  • Revogar consentimentos

Solicitações podem ser feitas via email: contato@vythalab.com.br
